Key Features

What makes this recommender production-grade

⚙

Hybrid Scoring Engine

Weighted ensemble combining TF-IDF content similarity (0.45), category overlap (0.25), popularity (0.20), and skill-level match (0.10) for robust recommendations.

💡

Explainable Results

Every recommendation includes human-readable reasons: "Very similar topics", "Shares the same categories", "Matches your skill level". No black-box suggestions.

📚

Skill-Level Awareness

Multi-signal skill classifier detects beginner, intermediate, and advanced books from title keywords, description text, and page count thresholds.

🔌

Live Google Books Fallback

Search first queries the local DuckDB database, then falls back to Google Books API for live results. New books are automatically ingested for future recommendations.

🛡

Rate Limiting Built-In

Sliding-window rate limiter (configurable via env vars) protects the API. Thread-safe singleton ensures safe concurrent access to the recommendation model.

📈

Weekly Data Refresh

GitHub Actions CI/CD pipeline ingests fresh books across 75+ topics every Monday, keeping the catalog current without manual intervention.

Scoring Signals

How the hybrid ensemble computes recommendation scores

Weight: 0.45

Content Similarity

TF-IDF vectorization of title + description text. Cosine similarity between the query book and every candidate. Captures topical relevance.

Weight: 0.25

Category Overlap

One-hot encoded category membership. Normalized dot product measures how many BISAC/Google categories two books share.

Weight: 0.20

Popularity Score

Bayesian-style: rating * log(1 + ratings_count), normalized to [0, 1]. Favors well-reviewed books without over-penalizing new ones.

Weight: 0.10

Skill Match

Progression-aware matching: exact level = 1.0, beginner-to-intermediate or intermediate-to-advanced = 0.5, otherwise 0.0.

API Reference

REST endpoints for search and recommendations

EndpointMethodParametersDescription
/health GET — Health check with uptime and DB row count
/search GET q (string, min 2), limit (int, default 10) Search books by title/description. Falls back to Google Books API if local results are sparse.
/recommend/by-book GET volume_id (string), top_n (int, default 10) Get hybrid recommendations with per-signal breakdown and human-readable reasons.

Quick Start

Run the platform locally in under 5 minutes

# Clone and install
git clone https://github.com/JepStar990/book-recommender-platform.git
cd book-recommender-platform
make install

# Set up environment (optional: add GOOGLE_BOOKS_API_KEY)
cp .env.example .env

# Ingest books from Google Books API
make ingest

# Launch API (http://localhost:8000)
make run-api

# In another terminal, launch frontend (http://localhost:8501)
make run-frontend

Who benefits from this platform

Find the next book at your skill level. The progression-aware scoring ensures you're not jumping from a beginner book straight to an advanced one.

Course Designers

Discover books in related categories with similar difficulty. Build reading lists that scale from fundamentals to mastery.

MLOps Portfolio

Demonstrates production ML engineering: data ingestion, feature engineering, model ensemble, API serving, CI/CD, and explainability.

Book Clubs

If you enjoyed one book, find others that match in topic, category, difficulty, and quality. Transparent reasoning builds trust in suggestions.
